## 1. Unity-MCP: Open-Source AI Bridge for Unity Engine

- **title**: Unity-MCP Brings AI Agents Directly Into Unity Editor and Runtime
- **title_zh**: Unity-MCP 开源工具：AI 智能体直接接入 Unity 编辑器与运行时
- **summary**: Unity-MCP is an open-source plugin that connects Claude, Cursor, Copilot, and other AI agents to Unity via the Model Context Protocol (MCP). Unlike other tools, it works inside compiled games, enabling real-time AI debugging and dynamic NPC behavior. With 70+ built-in tools spanning project assets, scene hierarchy, scripting, and editor operations, it allows developers to automate workflows and generate code without vendor lock-in. The significance lies in its runtime capability—AI can now operate within live games, not just during development. This bridges the gap between AI-assisted coding and in-game AI systems, potentially accelerating both development and player-facing AI features.
- **summary_zh**: Unity-MCP 是一款开源插件，通过 MCP 协议将 Claude、Cursor、Copilot 等 AI 智能体接入 Unity 编辑器与运行时。与其他工具不同，它能在编译后的游戏内运行，支持实时 AI 调试和动态 NPC 行为。该插件内置 70 多个工具，涵盖项目资产、场景层级、脚本和编辑器操作，开发者可自动化工作流并生成代码，且无厂商锁定。其核心意义在于运行时能力——AI 不再仅限于开发阶段，而是可以直接在实时游戏中运作。这填补了 AI 辅助编码与游戏内 AI 系统之间的鸿沟，可能同时加速开发效率和玩家-facing 的 AI 功能迭代。对于独立开发者而言，这意味着无需深厚技术背景即可实现复杂的 AI 驱动功能。

## 4. Fire Field: Solo Developer Ships Diablo-like ARPG Using AI in 3 Months

- **title**: Solo Developer Ships Commercial Diablo-like ARPG in 3 Months Using AI Tools
- **title_zh**: 独立开发者借助 AI 工具三个月内发布商业级暗黑风 ARPG《Fire Field》
- **summary**: Naoki Fujinaga, a 45-year-old Japanese solo developer with no prior game development experience, shipped Fire Field on Steam in roughly three months using AI as his primary development partner. He built a custom JavaScript engine from scratch, generated approximately 120,000 lines of code with Claude Code, and used AI for art, music, video, and localization (95 subtitle languages, 70 voice dubs). The game represents a concrete example of AI-enabled solo development—achieving scope and quality previously requiring teams. However, Fujinaga notes bug fixing grew exponentially with feature additions, highlighting that AI accelerates creation but doesn't eliminate technical debt. The case demonstrates both the potential and limitations of AI-assisted game development for solo creators.
- **summary_zh**: 45 岁的日本独立开发者 Naoki Fujinaga 在没有游戏开发经验的情况下，借助 AI 作为主要开发伙伴，在约三个月内将暗黑风格 ARPG《Fire Field》发布到 Steam。他从零开始用 JavaScript 构建了自定义引擎，通过 Claude Code 生成了约 12 万行代码，并使用 AI 生成美术、音乐、视频和本地化内容（95 种字幕语言、70 种配音）。该游戏是 AI 赋能独立开发的典型案例——实现了以往需要团队才能完成的规模和质量。然而，Fujinaga 指出随着功能增加，Bug 修复呈指数级增长，这凸显了 AI 加速创作但无法消除技术债务的现实。该案例同时展示了 AI 辅助游戏开发的潜力与局限性，为其他独立开发者提供了可借鉴的实操经验与警示。
- **sourceUrl**: https://koreagamedesk.com/solo-game-developer-ships-diablo-like-indie-game-using-ai/
