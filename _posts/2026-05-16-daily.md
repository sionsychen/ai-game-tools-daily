    title_zh: "Anthropic的Claude托管代理现在可以'做梦'了"
    summary: "Ars Technica reports that Anthropic has introduced 'dreaming' to Claude Managed Agents at its Code with Claude developers' conference. Dreaming is a scheduled process in which the AI reviews recent events and cross-agent sessions to identify patterns worth storing in long-term memory. Unlike standard context compaction, which happens within a single conversation, dreaming analyzes information across multiple agents and sessions, surfacing important patterns for future tasks. Users can choose between automatic dreaming or manually reviewing memory changes. The feature raises fascinating possibilities for game developers building persistent AI NPCs that evolve over time."
