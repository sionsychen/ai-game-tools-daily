    title_zh: "开源实验性 AI 将文字提示转化为可玩的漫威、星球大战与哈利波特游戏"
    summary: "Researchers at CUHK's MMLab have released OpenGame, an open-source AI framework they claim is the first to autonomously build complete playable browser-based games from natural language prompts. Using a specialized GameCoder-27B model trained with reinforcement learning on actual code execution, the system structures projects, writes code, debugs errors, and generates final games across over 150 game types. An evaluation system called OpenGame-Bench judges generated games on health, usability, and prompt fidelity, then iteratively corrects errors until playability is achieved."
    summary_zh: "香港中文大学 MMLab 研究团队发布 OpenGame，他们声称这是首个能从自然语言提示自主构建完整可玩浏览器游戏的开源 AI 框架。该系统采用专门训练的 GameCoder-27B 模型，通过强化学习在实际代码执行上进行训练，可自动构建项目、编写代码、调试错误并生成最终游戏，支持超过 150 种游戏类型。一个名为 OpenGame-Bench 的评估系统会从健康度、可用性和提示匹配度三方面评判生成结果，并迭代修正错误直至游戏可玩。"
