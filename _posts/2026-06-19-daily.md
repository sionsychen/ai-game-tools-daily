### Article 2: NVIDIA Launches ACE Game Agent SDK Beta for On-Device AI Companions

- **title**: NVIDIA Launches ACE Game Agent SDK Beta for On-Device AI Companions
- **title_zh**: NVIDIA发布ACE Game Agent SDK测试版：支持本地运行的AI游戏伙伴
- **summary**: NVIDIA unveiled the ACE Game Agent SDK Beta at Unreal Fest 2026, enabling developers to integrate AI companions directly into games running on GeForce RTX GPUs without cloud dependency. The SDK features Unreal Engine 5 plugins for speech recognition, small language models, and text-to-speech, with a lightweight C/C++ agentic framework. Notably, ACE Game Agents can run on GPUs with only 8GB of VRAM including RTX 3060 cards, making on-device AI NPCs accessible beyond high-end hardware. The SDK includes three key APIs: Agent API for multi-step reasoning, Chat API for inference control, and RAG API for game-specific knowledge retrieval. NVIDIA is also partnering with Epic to integrate ACE with Unreal Engine's MetaHuman NPC technology for voice synthesis and emotional facial animation. This represents a significant shift toward local, privacy-preserving AI game characters that don't require constant cloud connectivity.
