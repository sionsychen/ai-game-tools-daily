## 1. Unity-MCP: Open-Source AI Bridge for Unity Engine

- **title**: Unity-MCP Brings AI Agents Directly Into Unity Editor and Runtime
- **title_zh**: Unity-MCP 开源工具：AI 智能体直接接入 Unity 编辑器与运行时
- **summary**: Unity-MCP is an open-source plugin that connects Claude, Cursor, Copilot, and other AI agents to Unity via the Model Context Protocol (MCP). Unlike other tools, it works inside compiled games, enabling real-time AI debugging and dynamic NPC behavior. With 70+ built-in tools spanning project assets, scene hierarchy, scripting, and editor operations, it allows developers to automate workflows and generate code without vendor lock-in. The significance lies in its runtime capability—AI can now operate within live games, not just during development. This bridges the gap between AI-assisted coding and in-game AI systems, potentially accelerating both development and player-facing AI features.
- **summary_zh**: Unity-MCP 是一款开源插件，通过 MCP 协议将 Claude、Cursor、Copilot 等 AI 智能体接入 Unity 编辑器与运行时。与其他工具不同，它能在编译后的游戏内运行，支持实时 AI 调试和动态 NPC 行为。该插件内置 70 多个工具，涵盖项目资产、场景层级、脚本和编辑器操作，开发者可自动化工作流并生成代码，且无厂商锁定。其核心意义在于运行时能力——AI 不再仅限于开发阶段，而是可以直接在实时游戏中运作。这填补了 AI 辅助编码与游戏内 AI 系统之间的鸿沟，可能同时加速开发效率和玩家-facing 的 AI 功能迭代。对于独立开发者而言，这意味着无需深厚技术背景即可实现复杂的 AI 驱动功能。

## 3. Daz Studio 6: AI-Enhanced 3D Character Creation Platform

- **title**: Daz 3D Launches Daz Studio 6 with Integrated AI Chat and Performance Upgrades
- **title_zh**: Daz 3D 发布 Daz Studio 6：集成 AI 聊天与性能升级的数字人创作平台
- **summary**: Daz 3D released Daz Studio 6, adding Victoria AI Chat for in-app assistance, faster asset loading, improved content organization, and support for latest NVIDIA GPUs. The platform is widely used for digital human creation across gaming, entertainment, and virtual production. While not exclusively a game tool, Daz Studio's character assets are frequently used in game development pipelines. The AI chat integration represents a practical application of AI assistance in creative workflows—helping artists troubleshoot and find content without leaving the application. The release highlights how established 3D content platforms are incrementally integrating AI to reduce friction in creative workflows rather than replacing artists entirely.
- **summary_zh**: Daz 3D 发布了 Daz Studio 6 版本，新增 Victoria AI Chat 应用内助手、更快的资产加载、改进的内容组织功能以及对最新 NVIDIA GPU 的支持。该平台广泛应用于游戏、娱乐和虚拟制作领域的数字人创作。虽然并非专门的游戏工具，但 Daz Studio 的角色资产经常被用于游戏开发管线。AI 聊天集成代表了 AI 辅助在创意工作流中的实际应用——帮助艺术家在应用内解决问题和查找内容，无需切换窗口。此次发布凸显了成熟的 3D 内容平台如何渐进式地整合 AI，以减少创意工作流中的摩擦，而非完全取代艺术家。对于游戏开发者而言，这意味着更高效的数字人资产获取和定制流程。
