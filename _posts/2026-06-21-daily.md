### 4. NVIDIA ACE Game Agent SDK Enables Local AI Companions on RTX GPUs

**Category:** ai-npc
**Source:** [Tech-Critter](https://www.tech-critter.com/local-ai-companions-npcs-unreal-engine/)

**Summary (EN):**
NVIDIA's ACE Game Agent SDK represents a strategic shift from cloud-based to on-device AI for gaming. The open-source C/C++ framework enables developers to build AI companions and NPCs that run locally on RTX hardware, eliminating latency and server costs. The SDK includes three core APIs: Agent API for perception and reasoning, Chat API for dialogue, and RAG API for context retrieval. NVIDIA also released UE5 plugins supporting ASR (8 languages), small language models (Qwen 3.5 4B), and TTS (Chatterbox Turbo 350M). The PUBG Ally beta—an AI teammate that understands voice commands and makes tactical decisions—demonstrates real-world application. This move addresses two major barriers to AI NPC adoption: latency and operational costs, potentially accelerating mainstream adoption of intelligent companions in games.

**Summary (ZH):**
NVIDIA ACE Game Agent SDK标志着游戏AI从云端向本地设备的战略转移。这个开源C/C++框架使开发者能够在RTX硬件上本地运行AI伙伴和NPC，消除延迟和服务器成本。SDK包含三个核心API：Agent API（感知与推理）、Chat API（对话）和RAG API（上下文检索）。NVIDIA还发布了UE5插件，支持ASR（8种语言）、小语言模型（Qwen 3.5 4B）和TTS（Chatterbox Turbo 350M）。PUBG Ally beta——一个能理解语音指令并做出战术决策的AI队友——展示了实际应用场景。此举解决了AI NPC普及的两大障碍：延迟和运营成本，有望加速智能伙伴在游戏中的主流采用。对于正在评估AI NPC技术方案的游戏工作室，NVIDIA的本地优先策略提供了区别于云端方案的可靠替代路径，特别是在实时性要求高的竞技和合作游戏场景中。
